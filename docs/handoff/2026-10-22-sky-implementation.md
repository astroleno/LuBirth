## 已落地

- 中国 / 现代两套文化入口。中国保留 339 条宋代绘图记录，支持三垣和四象分组；广角突出六道垣墙、28 主宿，放大后展开其余连线与名称。两条星团记录仍不绘制，实际可选 337 条，未把这个数当历史星官总数。
- 现代 88 个条目、85 条原图映射均保留。图绘由「只显示选中一幅」变为视域内多幅，同一恒星锚点投影，桌面最多 8 幅、窄屏最多 5 幅；选中项优先，邻近图绘保留。
- 一块底部玻璃表面承载浏览、观测、画面、对象详情和出处。名称直接排字，避让标题、控制表面及其他名称。选中图绘的名称移到图像边缘外；面板过近时隐藏该天空名称，详情标题仍保留。
- NASA 坐标化银河底图。实际选择 `milkyway_2020_4k.exr`，**官方明确此文件已去除 Hipparcos / Tycho 亮星，且为赤道坐标版本**；不是 `_gal` 文件。进一步低通生成 1024×512 的星密度氛围层，约 576 KB；与恒星使用同一 J2000 → 地平坐标旋转。
- 心月狐、尾火虎两张透明原创样张，冻结来源与 HIP 控制点。传统动物对应与当代造型分开说明，未声称玉皇庙彩塑复原；不复制第三方未授权星君图。
- 按需载入、短暂渐显、12 项 / 64 MiB 解码纹理预算，按需逐出；大图异步解码并缩小 GPU 上传尺寸，着色器提前编译。静止不维持动画循环。

## 帧率问题：两个原因须分开

1. **静音宿主调度。** Ego 空 `requestAnimationFrame` 对照在 6.5 秒内只回调 7–8 次，间隔最大约 1,022 ms；没有执行绘图。焦点模拟也未消除。该环境的连续 FPS 不能用于判定渲染负载，但仍用于功能、触控模拟和画面验证。数据在 [browser-cadence.json](../../output/sky-implementation-20261022/browser-cadence.json)。
2. **应用 30 Hz 截止时间窗口过窄。** 在可见 IAB 中，浏览器回调约 60 Hz，原来 .1 ms 容差会因时间戳量化/抖动错过第二次回调，形成约 16 / 50 ms 的不均匀节奏。容差调整为最多 2 ms，仍按绝对截止时间推进，不累积漂移；后台或长暂停后不补画大量帧。增加可复现的量化/抖动回归。

同一可见 IAB、1280×720、8 幅图绘、13 次绘制调用的对照：

| 项目 | 修正前 | 修正后 |
| --- | --- | --- |
| 六个采样窗口 FPS | 约 30 | 29.98–30.04 |
| 绘制间隔 P95 | 49.9–50.3 ms | 34.6–35.3 ms |
| CPU 提交 P95 | 0.2–0.6 ms | 0.2–0.4 ms |
| GPU P95 | 1.30–2.12 ms | 1.23–1.59 ms |
| 长任务 | 0 | 0 |

证据：[修正前](../../output/sky-implementation-20261022/visible-before-cadence-fix.json)、[修正后](../../output/sky-implementation-20261022/visible-after-cadence-fix.json)。CPU 指提交耗时，GPU 为异步 timer query；没有把两者混用。

390×844、设备 DPR 3（实际绘图 DPR 1.5）、5 幅图绘的**桌面浏览器手机模拟**：四个窗口 29.98–30.00 FPS，间隔 P95 34.1–34.4 ms，GPU P95 0.69–1.18 ms、无长任务。[数据](../../output/sky-implementation-20261022/visible-mobile-performance.json)。这不是 iPhone Safari 真机结果。

同一手机画幅内，通过真实画布的键盘处理器连续派发 101 次方向键事件，转向超过一圈并更换图绘：5 个不同统计窗口 29.92–30.05 FPS，间隔 P95 34.9–37.0 ms，CPU P95 0.7–0.8 ms，无长任务。缓存保持 12 项、活动图绘 5 幅，最高估算约 12.6 MB，无纹理失败或控制台错误。[连续转向数据](../../output/sky-implementation-20261022/visible-mobile-motion.json)。这是合成键盘交互负载，不能代替真机触摸性能。

关闭连续测量后，2 秒内累计绘制保持 320 → 320，单画布。[静止证据](../../output/sky-implementation-20261022/visible-idle.json)。

首次图绘接入时曾测到一次 112–119 ms 的 CPU 提交峰值。现已增加解码尺寸上限、异步解码和预编译，但上述稳定窗口不等于完全冷缓存性能测试；网络冷加载、驱动冷编译和真实手机首帧仍需独立测试。当前构建主入口约 2 MB、gzip 约 728 KB，构建器仍提示大包。

## 正确性与交互验证

- `node scripts/test-sky-spike.mjs`：13 项通过。保留 60 个 Stellarium 26.3 桌面采样回归，现代最大差 5.596″、共享 EQJ 转换最大差 2.478″。**不是本轮重新操控桌面软件取样。** 古代天狼星 / 南门二最大约 6.88′ 差异继续明确保留。
- `node scripts/test-sky-presentation.mjs`：7 项通过，覆盖量化时间戳节奏、三垣四象分组、87 条图绘的三个 HIP 锚点跨日期/半球映射、NASA 坐标轴与输出哈希、手机视锥剔除，以及 25° / 70° / 110° 视场的选择优先与数量上限。
- 实际 GPU 星点材质 12 项通过：星等亮度单调、冷暖可辨、缺失 B−V 中性白、缩放点光源表现、DPR 1 / 1.5 / 2 / 3、遮挡与白昼渐隐等。脚本：`scripts/verify-sky-star-rendering.mjs`，无 shader error。此测试不声称校准光度或逐像素匹配 Stellarium。
- TypeScript 单独检查 spike 入口通过；独立 Vite 构建通过，输出到 `output/sky-implementation-20261022/build`，未覆盖原版 dist。
- 手机布局检查覆盖 390×844 与 844×390。最终 Ego 双指验证在同一次执行中显式设置并读取 390×844 视口，视场从 70° 缩到 36.842°；网页缩放仍为 1，无横向溢出、单画布。[带视口尺寸的手势记录](../../output/sky-implementation-20261022/mobile-gesture-verified.json)。早期截图工具有宿主缩放差异，最终手机图使用 CDP 按 390×844 CSS 画幅捕获：[中国图绘](../../output/sky-implementation-20261022/phone-chinese-final.png)、[出处面板](../../output/sky-implementation-20261022/phone-sources-final.png)。
- 可见 IAB 中检查控制台无 warning/error。样张和来源说明均可在同一玻璃表面中访问。
- [现代多图绘桌面实拍](../../output/sky-implementation-20261022/modern-desktop-final.png)。预览保留两套文化切换；中国样张入口为「中国星空 → 星官 → 夏夜图绘样张」。

## 信源与模块入口

| 内容 | 入口 | 核实边界 |
| --- | --- | --- |
| 冻结星表、文化包、原图 | `src/spikes/sky/data/manifest.json`、`README.md` | 原始数据哈希不变；成分星代理、M7 / M44 缺口保留 |
| 银河加工 | `scripts/prepare-sky-background.mjs`、`data/milky-way-density.json` | 源 URL、哈希、赤道映射及处理算法已记录；固定 J2000 弥散形态 |
| 中国样张 | `data/chinese-art/manifest.json` | 生成记录、原 PNG 哈希、HIP 控制点和各字段状态；动物对应见 CText 索引文本，直接页面本轮 403 |
| 文化层次与视域 | `skyPresentation.ts`、`skyCultures.ts` | 三垣 / 四象沿上游分区代码组织；不是新考证的宿区边界 |
| 图绘、资源预算 | `SkyArtwork.tsx`、`ConstellationArt.tsx`、`artTextureCache.ts` | 图像跟随天球，CPU/GPU资源按实际解码尺寸估算 |
| 控制与出处 | `main.tsx`、`sky.css` | 所选对象关联星位、文化、图绘三个不同来源 |
| 节奏与标签 | `skyPerformance.ts`、`SkyRuntime.tsx` | 绝对截止时间，有限提前容差；实际矩形避让 |

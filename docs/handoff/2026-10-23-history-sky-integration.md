# 古星图、出生星空与古今同源：实现与验收

日期：2026-10-23。对应设计：[联动方案](../plans/2026-10-23-001-feat-history-sky-link-plan.md)。

## 已实现的体验

主页面现有“地月 / 观天 / 古今同源”三个入口。个人出生信息成为统一观察基准；地月和观天消费同一 UTC 与经纬度，并分别保留自己的构图。

| 操作 | 实际变化 |
| --- | --- |
| 保存出生时刻 | 明确公历日期、钟点、地点与 UTC 偏移；同时更新地月和观天 |
| 选择古星图 | 在陈卓、宋代、元代、现代 88 星座之间切换，保留时间、地点和观察方向 |
| 进入人物／事件的天空 | 展示原历、换算日期、来源及不确定性；用户选定演示钟点、地点和时间解释后进入 |
| 返回出生时刻 | 恢复个人日期、地点及各视图原构图；未输入出生信息时可返回此前示例 |
| 查找联系 | 同月同日、相近时节、人物／事件、年代、历史上的今天、搜索与收藏 |

“同月同日”采用个人出生当地日期和资料换算公历日期；“相近时节”为年内相距不超过 14 天，不能解读为同农历生日、同月相或相同天象。文化版本仅提供理解天空的方式，不声称该人物曾经使用它。

主入口：`/lubirth/`；直接进入资料：`/lubirth/?scene=sky&history=1`。原独立入口 `/lubirth/sky-spike.html?view=yuhuang` 继续可用。

位置依据是项目已有经纬度表与独立的 `reference/history/location-overrides.json`。代表点不是历史宅院坐标；贵州、福建省域、柳林同名地、北京至汉口线路等没有被自动补成出生地。用户填写的坐标只作为本次演示位置。

新增陈卓体系 317 个星官记录和元代体系 187 个记录，冻结为 Stellarium v26.3 数据，保留索引、说明、作者、CC BY-SA 4.0 授权和文件哈希。宋代原有 339 个星官、28 幅人物图绘和 56 张配对图片保持原配准及文件哈希。

为接齐历史星官的恒星标识，从同版本 HYG 补入两颗恒星。HIP 115125 采用有交叉标识依据的 HIP 115126 分量代理，另两项代理沿用既有实现；代理限制仍明确记录。M31、M44、M7 非恒星对象未伪装成恒星绘制。敦煌星图保留史料入口，不冒充已完成独立逐星复刻。

个人出生信息保存在当前浏览器会话；文化偏好和收藏保存在本机。存储被拒绝或内容损坏时，界面仍可使用并提示。没有新增账户或发送个人出生信息的服务请求。

后续目录可作为导入脚本的第一个参数，目标目录作为第二个参数。先检查当前指定目录而不替换应用文件：

```sh
node scripts/prepare-history-catalog.mjs --check
```

`--check` 完整验证来源、日期／JDN、重复 ID、链接和坐标，并输出新增、删除、字段变化及日期／地点的前后值。核对后执行默认导入：

```sh
node scripts/prepare-history-catalog.mjs
```

输出为 `records.json`、`manifest.json`、`import-diff.json`。记录 ID 保持稳定；来源、日期或地点映射变化会改变记录哈希。旧历史演示仍保留当次参数，重新打开资料时会提示更新，避免静默改写用户正在看的天空。新地点继续采用明确映射或让用户选择；精确 UTC 等超出现有日期级契约的新字段需先调整适配，不能静默丢弃后冒充准确时刻。

浏览器实际走通以下场景：

- 上海出生日期 `2000-01-14 00:05 UTC+08:00` 转为 `2000-01-13T16:05:00Z`，“同月同日”仍匹配 1 月 14 日的苏轼和周信芳。
- 苏轼 `1037-01-14 20:00`、眉山代表点 `30.048318, 103.831788`、地方平太阳时，两个视图均使用 `1037-01-14T13:04:40Z`；秒数没有丢失。
- 张之洞的原地点仍为贵州且无默认代表点。用户选择 `0°, 0°` 和 `UTC−05:00` 后，`1837-09-02 20:00` 转为次日 `01:00Z`；两个视图一致。
- 四种文化逐一切换，UTC、经纬度不变；每次仅一个场景画布。独立图绘入口正常，采样时 7 个活跃图绘纹理约 21.4 MiB，低于既有 64 MiB 缓存上限。
- 个人观天方向 `5° / 35° / 73.913°` 在进入历史再返回后恢复。地月近景往返的相机配置和地球尺寸完全一致，见 `earth-return.json`。
- 连续保存夏至／冬至日期，太阳仰角立即切换而方位保持一致，见 `seasonal-input-changes.json`。
- 收藏刷新后保留；人物／事件和宋代筛选、无结果搜索、今天条目、条件日期未确认禁用、切换记录后钟点与确认重置、键盘 Tab 与 Escape 焦点恢复通过。
- 检查 1450×713、390×844、320×640、844×390 尺寸；列表、表单和文化入口可滚动，无横向溢出。390×844 下完整历史观察及返回流程见 `mobile-journey.json`。

浏览器验收发现并修复了新增星点与旧颜色／星等缓冲数量不一致的问题，并加入直接检查实际绘制几何的回归断言。另修复了短年份季节／月球日序计算、连续修改观察日期时的季节更新节流，以及详情切换后的键盘焦点。

现有 `runSolarFullTests` 中旧的 `fixedSunAz`、`seasonal` 独立钩子未注册，仍返回 `null`；不将它们计为通过。本轮以时间测试中的方位固定／季节断言及浏览器连续日期切换覆盖相应行为。

## 仍然成立的限制

- 本轮交付的是有来源、有假设说明的历史天空演示；未把日期级资料升级为已知出生或事件瞬间，也未完成剩余史料考订。
- 仍有 34 条地点需要选择。全年覆盖与早期年代覆盖仍不完整，可由后续定向采集补充。
- 古代双星自行、代理恒星、未验证宿界和未显示深空对象沿用／明确保留限制；不能据此声称完整精确复原历史目视天空。
- 手机验证是 Chromium 尺寸模拟，未完成真机 iPhone Safari 或设备性能基准。

本轮未创建分支／worktree，未启动新 agent，未提交、推送或发布。

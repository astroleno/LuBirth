# 玉皇庙图绘：夜空线稿与完整原型

后续进展：本文件保留两幅样张阶段的记录；全套 28 × 2 已制作并接入独立 spike，当前状态见 [二十八宿完整交付记录](2026-10-22-yuhuang-28-pairs.md)。

## 本轮范围与呈现约定

依据用户确认：只在独立星空 spike 中迭代。心月狐、尾火虎各保留两种资产，夜空呈现统一亮度的透明高光线稿；点击星宿名称，直接展开完整淡彩原型，另可打开实物照片对照。原版地月页面、星位和星等不变。

模块与接口：

- `chinese-art/manifest.json` 的 `image` 保留淡彩原型，新增 `skyImage` 及其来源哈希；准备脚本可重建两版注册信息。
- `skyCultures.ts` 只将 `skyImage` 送入天空绘制；`CHINESE_ARTWORK` 保留完整双版本记录。
- `ConstellationArt` 为线稿提供同一线色，`SkyArtwork` 使用同一不透明度，不因选中切换亮度。沿用既有透明图层、投影和纹理缓存。
- `main.tsx` 和 `sky.css` 在既有单层玻璃面板里展示完整原型，桌面左右排布、手机上下排布；原型用 contain 保留全身，实物对照继续可用。

验收：两幅线稿透明、造型可辨、同一亮度尺度；夜空中无大块淡彩填充；点击心宿或尾宿即可看到对应完整原型；关闭、切换另一幅和实物对照可用；桌面与手机尺寸无裁头裁脚、横向溢出；配准、类型检查和独立构建通过。真实 iPhone Safari 不以桌面模拟代替。

## 实施与验证

已实现：

- 两幅新线稿均为 1086×1448 透明 PNG，由既有淡彩原型进行 AI 辅助轮廓转绘。使用同一象牙白 `#e5ddc9`、0.70 不透明度；选中时不再单独加亮。减少衣甲和毛发的密集细节，让恒星透过图绘。原型文件 SHA-256 与上一版完全相同。
- 天空只读取 `skyImage`；淡彩原型和照片只在对应面板出现时加载。两张线稿共约 3.02 MB，上一版淡彩两张约 4.52 MB。原型和线稿尺寸、HIP 注册控制点一致，13° / 16° 的角宽保持不变。线稿是绘画转译，不能声称每一条纹样逐像素相同。
- 点击心宿 / 尾宿名称直接显示完整原型。单层玻璃面板桌面左右排布，手机上下排布。原图 contain 呈现，切换另一幅、实物对照、回到夜空、Escape 收起可用。面板切换时回到顶部，避免返回后裁住头部。
- 修复本次严格类型检查发现的两处三维向量累加类型推断，并将一处 `Array.at` 改为等价 `pop` 以符合当前 ES2020 配置；计算数值不变。

## 边界与未完成项

本轮只改两幅现有样张的双版本呈现，**其余 26 幅仍未制作**；真实 iPhone Safari 与完全冷缓存启动尚未验证。上述帧率为桌面可见浏览器的窄屏稳定采样，不能外推为手机真机表现。独立构建仍提示约 2.03 MB 的主包较大。

本轮不修改星位、星等、颜色模型或主页面，也没有提交、推送或发布。Ego 静音验证空间已结束；当前 IAB 保留线稿预览。

## 用户能感受到的变化

- 有代表点的历史事件直接显示日期、地点和当地 20:00 演示摘要，一次明确确认即可观看合照，不再重新搜索已有地点或另勾同一说明。
- 自选地点点击一次候选或用键盘确认一次即生效。改查另一地点、清空查询或只选择部分省市时，不能提交之前的坐标；可取消改选。
- 坐标编辑回填原值，只改名称或一个坐标即可。地点收敛为摘要，地名去掉重复的城市中心名称。
- 返回目录、切分类、关闭重开后保留设置和阅读位置；详情的返回入口随阅读保留。不同记录和变更过的资料哈希不共用旧确认。
- 史料和完整日期解释改为按需展开。沿用地点说明真实来源；历史日期不再进入个人出生初值。
- 留念等待画面真正可截图后才可使用。卡片失败显示明确错误、重试和保存原图入口；三套导出失败不影响已完成的单张 PNG。
- 默认合影位置、蓝色弧光、手写加载、地月近景和沉浸观看保持；不增加常驻历史文字或水印。星空、月相、太阳与坐标算法未修改。

## 页面实测

本地开发页：`http://127.0.0.1:5183/LuBirth/?history=1&spatialtest=1`。一个 Ego Lite 独立工作空间、一个复用页面；已关闭测试工作空间。桌面 1440 × 900、DPR 1；手机视口 390 × 844、DPR 2。使用合成测试资料，没有操作用户前台或发布页面。

| 路径 | 结果 |
| --- | --- |
| 上海 → 查询北京／清空／只改省份 | 主操作禁用，不提交旧上海；取消可恢复。候选 Enter 只选地点，不提交外层表单。 |
| 组合输入、Escape、候选焦点 | 合成的中文组合事件不提交；Escape 先收候选，面板保留；选择后焦点落在更改地点动作。真实输入法未测。 |
| 名称、单项坐标与越界修正 | 经度、纬度及名称回填；只改一项保留其他项；纬度 91 时阻止提交，改正后恢复。 |
| 承天寺夜游首次详情 | 黄州代表点、当地 20:00 与主操作首屏可见；按钮顶部桌面约 435px、手机约 572px，无单独确认勾选。 |
| 一次确认进入合照 | 保留合影及沉浸；黄州 20:00 对应 `1083-11-30T12:20:29.000Z`，进入原有地月近景。 |

| 历史后首次出生／刷新／未保存草稿 | 出生初值不再是 1083 年；未保存的出生草稿在分类往返时保留。手机实际保存出生合照后，历史往返恢复该个人基准。 |
| 当地星空与文化 | 四种文化切换均保留同一观察；地月与观天沿用相同 UTC 和坐标；真实位置可选，再切回合影正常。 |
| 即时切景与截图恢复 | 观天 → 地月的重建阶段显示禁用的「画面准备中」；就绪后可留念。模拟截图中断显示内联重试，无阻塞弹窗，重试成功。 |
| 卡片和三套导出故障注入 | 阻断本地模板资源触发失败；重试成功且冻结原图哈希不变。手机错误、重试和原图操作均在视口内。批量失败时单张 PNG 仍可保存。 |
| 实际下载 | 桌面 PNG 1440 × 1845、手机 PNG 390 × 1100，均通过 PNG CRC 和原模板元数据核对；已查看导出图片，日期、历史演示及默认 20:00 说明正确。三套 ZIP 实际下载，三张 PNG 及 ZIP CRC 正常。 |

## 性能和未完成验收

| 开发版后台工作空间采样 | 实际结果 |
| --- | --- |
| 桌面静置 10 秒 | 123 帧，约 12.3 FPS；21 次场景绘制调用／帧 |
| 手机视口静置 10 秒 | 26 帧，约 2.6 FPS；12 次场景绘制调用／帧 |
| 手机视口启用页面焦点模拟的诊断采样 | 5.01 秒、80 次浏览器回调、78 帧，约 15.6 FPS；没有激活系统前台窗口 |

**这些样本没有达到稳定 30 FPS。** 焦点模拟前后差异很大，且缺少同环境旧版基线；不能据此断言本轮提高或降低了性能，也不能确定瓶颈来自机器资源还是应用。生产构建通过不等于生产帧率通过。本轮没有增加渲染通道，地点草稿也不发布到全局观察，但这些结构约束不能替代性能实测。

实体 iPhone、Safari、真实软键盘／中文输入法尚未验证。功能、视口和导出检查通过，不等于上述设备与流畅度验收通过；本轮不发布。

# LuBirth 前端 UI/UX 与「古今同月」审阅

日期：2026-10-28。性质：独立审阅与后续改进建议，**没有实施应用修改，也不包含提交、推送或发布**。

## 结论

「古今同月」的观察数据和地月合照已经接通：承天寺夜游可以用黄州代表点、当地 20:00 进入原有沉浸近景，再以同一时间地点进入观天。蓝色弧光、默认合影月球和干净构图值得保留。

用户对地点反复输入、确认的感受有具体依据，主要来自三种不同问题：

1. **输入与已选地点不是同一状态。** 已选上海后输入北京，按方向键、回车，会直接提交之前的上海。这是本轮最高优先级的正确性问题。
2. **既有选择没有贯穿编辑和返回。** 展开坐标编辑时三个字段为空；只改名称会清掉已选地点。返回目录再打开同一条历史记录，也会要求重新选地点、勾确认。
3. **观看动作位于长资料和表单之后。** 已匹配代表点的事件仍从空地点开始，观看按钮在桌面和手机初始视口之外。注意力先被投入填表，再进入与历史身份连接较弱的纯画面。

一次点击地点候选本身可以成功，本轮没有复现“同一个候选必须反复点击才能生效”。后续应优先修复地点状态和任务流程，保持现有地月视觉方向。

## 概念应保持怎样的一致性

| 用户正在决定什么 | 当前入口 | 应影响什么 | 必须保持的边界 |
| --- | --- | --- | --- |
| 谁的哪一天、在哪儿观看 | 出生／古今 | 观察日期、钟点、地点及来源 | 历史演示不能变成个人出生信息的隐式来源 |
| 以什么观看方式呈现 | 地月／观天 | 地月合照或当地天空的视角 | 切视图沿用同一份观察，不要求重新填地点 |
| 用哪种文化理解星空 | 星空中的文化选择 | 星官、星座及对应图绘 | 不因换图绘改写观察时刻、位置或月相 |
| 月球放在哪里 | 合影位置／真实位置 | 月球的呈现位置 | 默认合影；对应观察时刻的月相保持一致 |
| 怎么留住这一刻 | 留念中的原图／纪念卡 | 当前画面及其文字表达 | 冻结同一份画面和时地；演示及精度说明不能被包装成史实 |

「古今同月」应表达不同时代面对同一个月球的体验。古今两次观察应各自呈现对应月相，不需要强行画成相同月相；“同月同日／相近时节”也不表示月相相同。

核心承诺可表述为：**从一条有出处的时光，来到具体地点，在原有地月合照里看那一天的月亮。** 当地星空与纪念卡承接这一刻，主体验继续由地月合照承担。

## 建议的「古今同月」观看流程

这部分是下一轮交互提案，**需要确认后再实施**，不表示现在可以删除既有日期和地点校验。

1. **选记录。** 详情开头出现事件／人物、所用日期及本次演示摘要，主要观看动作处于首个内容区。
2. **已有可靠代表点。** 显示可采用的地区代表点及精度；缺时刻的具体事件显示默认当地 20:00。无需再搜索同一个地点。
3. **需要另选地点。** 输入、选择一个候选即完成有效地点选择；需要坐标时从已选值编辑。历史场景的可访问名称应为演示地点，而非“出生地点”。
4. **一次有语义的确认。** 如合并勾选和主按钮，按钮及邻近摘要必须明确承担“接受本次日期解释、地点与演示钟点”的意义。不能仅移除勾选并在代码里默认已接受；未知地点、条件日期与人物缺时刻继续按规则处理。
5. **进入原合影近景。** 默认合影月球和沉浸保持不变。用户可以直接看月亮，按需显示菜单、进当地星空或留念；同一条记录返回时继续原设置。

推荐将“原记录／地区代表点／自选演示点”用一条简短摘要讲清。避免在同一屏重复展示选点下拉、已选行、搜索全文和多处经纬度，也避免把数据审校术语放在主要观看路径里。

## 下一轮验收标准

| 验收路径 | 通过条件 |
| --- | --- |
| 已选 A，输入 B 或清空查询，未选新候选 | 不会无提示提交 A；可取消改选，明确恢复 A。 |
| 候选键盘与触屏选择 | 单次候选确认得到一致地名、坐标和有效状态；Enter 不误提外层表单；中文输入法组合期间不提交。真实手机／Safari 另做验证。 |
| 已选地点后编辑名称或一个坐标 | 其余值回填且保留；越界或不完整输入有就地说明，修正后一次完成。 |
| 已匹配代表点的日期级事件 | 首个主要内容区能看见演示摘要与观看动作，不要求搜索已有地点；默认 20:00 的演示性质、日期解释和代表点精度清楚。 |
| 同条记录自选地点与 21:30，返回目录再打开 | 当前会话内恢复草稿；不同记录不串用确认，资料哈希变化重新核对。 |
| 古今提交区 → 星空分类 → 古今，或关面板 → 重开 | 已选值、合理滚动位置和焦点连续，不再反复寻找提交区。 |
| 没有个人出生基准，先历史后出生 | 个人输入不把历史观察无说明地当作出生初值；已有个人草稿原样保留。 |
| 合照 → 观天 → 文化视角 → 合照 → 留念 | 沿用同一 UTC、地点和时刻来源；月相正确，默认合影、蓝色弧光和沉浸构图保留。 |
| 留念切景、图片失败和一次重试 | 准备与错误状态明确；重试不换取景或删演示说明；实际成功导出并核对 PNG 后，才能确认完整导出流程通过。 |

# 古今同月输入与焦点修复

用户已批准按再核实的 RR1–RR4 迭代，并要求 commit、push、同步腾讯服务器。沿用既有 Observation、历史草稿、单面板与沉浸合照架构；本文件细化本次实现接口与验收。

## 模块与接口

| 模块 | 本次变更 |
| --- | --- |
| `HistoricalObservation` | 用显式的钟点编辑状态控制首次必填输入，输入形成合法中间值时保持挂载。明确选定预设、完成观看或收起时间设置才结束相应编辑。主动展开地点编辑后聚焦新地点模式控件，收起后回到更改按钮。 |
| `observationDraft` | 增加仅包含地点模式、自选草稿、沿用地点及来源的 `HistoryPlaceSnapshot`。开始地点编辑时保存有效旧地点；取消只恢复地点，不覆盖此间另改的钟点或时间解释。快照随记录／资料哈希的会话草稿保存，草稿规则升级为 v2；已有 Observation 和收藏不变。 |
| `ObserverPicker` / `LocationSelector` | 增加可选的 `onReady(input)` 通知。只在用户主动启动更改、且焦点仍在该编辑区域或原控件移除后的页面主体时，将焦点交给已载入的搜索框。历史层统一提供取消，避免与内部取消重复。 |
| `JourneyPanel` | 记住进入详情时的结果位置；返回项消失后，优先聚焦相邻可见结果，无结果则聚焦目录搜索框，保留已记录的阅读位置。 |
| 发布工具 | 核对既有腾讯主机指纹与控制台身份，将旧源站执行工具校正到腾讯上海；实际源站发布沿用控制台 TAT／OrcaTerm 免密会话。继续使用现有不可变 COS/CDN 包和源站版本链接，不修改共享路由。 |

## 验收

1. 苏轼初次逐键输入 `21:30`、清空重填、分段编辑分钟，字段和焦点持续存在，实际 Observation 为最终输入值；人物无默认钟点，事件缺时刻仍默认当地 20:00。
2. 出生和历史地点用 Enter 展开，焦点立即到对应编辑控件；地点表加载完成后能接续，用户已转去其他控件时不夺回焦点；取消和选定后返回摘要。
3. 代表点→待选查询可直接取消，恢复名称、坐标、精度、来源和可用主操作；自选点、沿用点、缓存往返均可恢复。没有旧地点的记录不提供虚假的取消；取消地点不覆盖另改的时间。
4. 单项及多项收藏取消当前项后返回，目录立即有明确焦点；普通返回仍回原项，阅读位置保留。
5. 通过 TypeScript、地点草稿／历史／地月／纪念卡相关回归和生产构建；Ego Lite 单工作空间检查桌面与手机视口、截图和运行错误。真机／Safari 与稳定帧率按实际证据说明。
6. 只提交本轮相关应用、测试、评审／验收文档和发布工具；保护原有 dist、过程目录和归档分支。已授权直接在 main 提交推送，使用提交后的源码打包，腾讯候选逐文件校验后原子切换，验证双域名、大小写入口、版本标记、资源、关键功能及邻站；最后清理本轮临时包与测试工作空间。

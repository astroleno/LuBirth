# 古今同月与地点输入迭代

日期：2026-10-28。用户已明确要求按 [UI/UX 审阅](../reviews/2026-10-28-lubirth-frontend-review.md) 实施，优先消除地点重复输入和确认。本文件细化该已批准范围，不新增发布、分支或 agent 授权。

## 目标与保持项

- 地点候选选一次即生效；改查新地名或只改省市时，不能提交旧坐标。
- 有代表点的事件先呈现日期、地点和默认当地 20:00 的简短观看摘要，由一个明确主动作确认并进入合照。
- 保留默认合影月球、蓝色弧光、原沉浸近景、共享 Observation 与当前全部入口。不改天文／月相／光照算法，不增加常驻水印或新面板。
- 日期解释、代表点精度、未知地点需明确选择、人物及个人出生不自动补钟点的规则继续有效。
- 本轮修改和验证在现有工作区完成，不提交、推送或改动公网。

## 模块和接口

| 模块 | 责任与接口 |
| --- | --- |
| `LocationSelector` | 可受控的 `LocationSearchDraft { query, province, city, district, pending }`。`onDraftChange` 只修改输入草稿，`onLocationChange` 仅在明确选择有效候选／完整区县时触发。保留原有调用方的非受控用法。组合框支持上下键、Enter、Escape 和输入法组合保护。 |
| `observationDraft`／`ObserverPicker` | `ObserverDraft` 统一已选值、搜索草稿和坐标草稿；`resolveObserverDraft()` 是表单获取可提交地点的唯一入口。新查询待选择时返回空；坐标字段从已选值回填；有效的单项坐标修改可直接用于主操作；取消改选恢复已选快照。选择后收敛成一条地点摘要和更改动作。 |
| 历史草稿 | 按记录 ID＋资料哈希＋草稿规则版本缓存设置，独立于全局观察，输入不发布到三维场景。缓存限当前会话，保存地点模式、自选地点草稿、钟点来源、时间解释、已观看状态与调整区展开状态；无效缓存回到安全初值，资料变化不复用旧确认。 |
| `JourneyPanel` | 详情先放观看摘要和主操作，原历、出处、完整核验说明仍在同一详情按需展开。已有代表点直接作为可见提案；未知地点直接进入自选。主按钮文字及邻近说明承担日期／地点确认语义，严格解析器仍必须接收明确确认。沿用当前画面地点时保存所选地点快照及真实来源，不动态串用后来另一条历史地点。 |
| `ExperiencePanel`＋历史目录／详情 | 各分类保留滚动位置；目录和每条详情分别保留阅读位置与返回焦点。首次打开新记录回顶，普通开关与分类往返不回顶。 |
| `App`／出生表单 | 个人出生初值仅来自个人基准、此前个人示例或新示例，不能直接使用历史观察；已经编辑的出生草稿继续保留。历史观看前清楚呈现事件身份和日期，进入后仍为纯画面，显示菜单可查看同一观察摘要。 |
| 截图能力 | 画布注册并完成绘制后发布截图就绪状态；清理仅撤销自己注册的函数。留念入口订阅就绪状态，未就绪不提供假可用按钮；错误以内联可恢复反馈替代阻塞弹窗。 |
| `KeepsakeEditor`／`compose` | 明确原图、合成中、不可用、失败、可保存；显式重试只重做同一冻结画面和选项。失败时可直接保存原图，预览错误与批量导出错误分开；图片读取错误指明原图／寄语／标识阶段，不推断未证实的网络根因。 |
| 界面样式 | 保持一条工具栏＋一个面板；只提高面板局部背景遮挡，候选高亮、焦点和小屏操作区域清楚，不增加模糊或三维通道。 |

## 验收

1. 上海选定后改查北京、清空查询或只改省份，不能静默提交上海；取消改选可恢复，候选一次点击／Enter 得到一致地名和坐标。
2. 候选展开时 Enter 不提交外层表单；组合输入事件不触发提交；Escape 先关候选，键盘焦点可继续使用。
3. 已选地点只改名称或一个坐标，其他值保留；不完整或越界输入保留草稿并明确指出问题。
4. 承天寺夜游首次详情可见黄州代表点、默认当地 20:00 及主操作；无需重新搜索地点或单独勾选同一说明，明确确认后进入合照。无代表点和无钟点的记录仍须提供必要输入。
5. 同条记录自选地点与 21:30，返回目录、切分类或关闭重开后继续原设置和合理滚动位置；不同记录不串用地点来源与确认，资料哈希改变回到安全初值。
6. 无个人出生资料先观看历史，再首次打开出生／刷新历史入口，个人输入不显示历史日期为出生默认值；已有出生草稿保持。
7. 合照、观天、四种星空文化、返回个人与留念沿用同一观察；默认合影、蓝色弧光和沉浸近景保持。
8. 地月重建期间留念入口与实际截图能力同步；纪念卡失败有可见错误、重试和原图退路；成功实际下载 PNG 并核对图片、观察说明与元数据。重试不重新取景。
9. TypeScript、独立目录生产构建、相关历史／地点／地月回归通过；桌面与手机视口截图并检查错误日志。模拟组合事件不能代替实体手机／Safari 输入法验证，未测项目如实列出。

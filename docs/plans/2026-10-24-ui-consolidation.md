# LuBirth 界面整合方案

状态：界面整合已完成，2026-10-25 已沿用 main 提交、推送并同步公网；本地及线上验收通过，详见[发布记录](../deployment/lubirth-ui-consolidation-2026-10-25.md)。

## 目标

保留地月与星空的暗色、玻璃质感和沉浸构图，把目前分散的导航、出生表单、古今抽屉、星空工具栏与重复信息整合起来。场景作为主画面，常驻界面收敛为一条工具栏；同一时刻最多展开一个工作面板。

视觉上使用留白、字号和少量分隔线区分内容；取消普通按钮、说明区和选项组各自的外框，不移除必要的输入边界与焦点提示。面板统一短暂淡入／移出，切换内容不堆叠弹窗；尊重减少动态设置，不新增动画库。

## 信息与操作结构

| 位置 | 内容 | 合并掉的现有界面 |
| --- | --- | --- |
| 唯一工具栏 | LuBirth、地月／观天、探索、留念、沉浸控制 | 顶部导航、星空底部工具条、地月还原按钮组的独立外框 |
| 唯一工作面板 | 同一级的「出生／古今／星空／画面」四项，切换内容 | 地月出生侧栏、古今浮层、星空设置面板各自的标题、关闭按钮和嵌套导航 |
| 一处观察说明 | 当前来源、当地日期时刻、地点；历史可返回个人基准 | 历史返回区、星空大标题及日期地点摘要的重复呈现 |
| 留念编辑 | 一次打开，在同一界面选择原图或纪念卡 | 原图预览 → 再打开纪念卡的额外操作层级 |

- 「地月／观天」只负责观看方式，出生与历史不是另一种场景。
- 出生表单只保留一份，主要操作合并为「查看出生合照」：校验、保存个人基准、按该地点取景、进入沉浸观看。
- 古今的目录、详情和演示参数在同一面板内前进／返回；史料来源及日期不确定性继续可查看。
- 星空文化选择保留在一处，支持中国星官与现代 88 星座；文化切换保持当前画面。观天时的星官检索、图绘、详情和来源使用同一工作面板，不再增加一个底部浮窗。
- 月球位置、画质、图层、视差与全屏等放入「画面」，常用选项直接显示，诊断与少用参数收在一个次要展开项。
- 留念编辑保留模板、字号／位置、时间地点、署名、PNG、ZIP 和取消；预览不再套额外卡框，模板选项改成简洁的同级选择。
- 桌面使用同一侧栏，窄屏使用同一下方面板，横屏沿用侧栏；沉浸时收起面板和说明，保留紧凑的唤回入口。

## 模块与关键接口

| 模块 | 责任与接口 |
| --- | --- |
| `App.tsx` 与共享界面组件 | 统一拥有 `view: earth/sky`、`activePanel: birth/history/sky/appearance/null` 和沉浸状态；工作面板统一管理标题、关闭、滚动、焦点与键盘退出。 |
| `main.tsx` | 主网站使用共享界面；显式 `?dev=1` 继续使用独立 `SimpleTest` 调试外壳与控制台测试入口。 |
| `JourneyPanel.tsx`／出生表单 | 将内容与原有弹层外壳分离，使用受控分类及 `onSaveBirth(Observation)`、`onObserve(Observation)`、`onCulture(CultureVersion)`；出生与历史继续写入现有 journeyStore。 |
| `SimpleTest.tsx` | 提供整合界面模式与控件挂载位置，将现有画面控件放入共享面板；相机取景沿用现有 ViewTransfer，天文、月相、截图与渲染逻辑保持原有接口。独立调试入口保留原有外壳。 |
| `spikes/sky/main.tsx` | 提供整合界面模式、控件挂载位置和打开工作面板的回调；星官详情、图绘来源和画面设置仍由原有星空状态驱动，主网站移除独立工具条和重复标题。独立星空入口继续可用。 |
| `SceneScreenshot.tsx`／`KeepsakeEditor.tsx` | 使用单一留念界面及原图／纪念卡状态；复用冻结草稿、本地合成和下载接口，不增加上传或服务端状态。 |
| CSS／玻璃表面登记 | 统一工具栏、面板、表单与选项组的样式和间距；不新增渲染上下文或常驻绘制循环。 |

UI 临时状态与天文状态分开：不增加第二份 Observation、月相计算或文化偏好。控件通过组件属性及挂载位置对接，不增加供界面操作使用的全局控制台接口。

## 验收标准

1. 主网站在地月与观天中都只有一条常驻工具栏，同一时刻最多一个工作面板；不再出现古今面板与另一套画面面板叠加。
2. 出生、古今、星空与画面处于同一级；出生输入及文化选择无重复入口，普通说明和选项组没有独立卡框。
3. 出生保存与合照取景形成一次主操作；历史事件仍按所选地点和月相进入合照，无时刻事件继续默认当地 20:00。
4. 默认月球合影、沉浸构图、真实位置选项、个人基准返回及视图镜头恢复均通过实际操作验证。
5. 星官搜索、文化切换、图绘／来源、画面参数和原图／纪念卡导出全部可达；各项数据含义和史料说明保持准确。
6. 桌面、390px／320px 竖屏与窄横屏无横向溢出、标题／按钮遮挡和不可触达的保存操作；支持安全区、键盘操作、焦点恢复及减少动态。
7. 实际场景仍为一个画布、一颗月球；静止星空保持按需绘制。通过类型、生产构建和受影响回归，截图自行目视检查后交付。

本轮验收针对界面整合；前次记录的细腻档帧率、月球 GPU 增量、真机与后台恢复缺口仍单独保留。

## 实现与验收记录（2026-10-24）

新增 `components/experience` 统一工作面板、文化选择与场景控件挂载接口。出生与历史内容在分类切换时保留输入及检索状态；地月和星空控件通过同一个挂载位置显示。留念使用一个对话框，在原图与纪念卡之间切换；场景计算仍使用现有 Observation、journeyStore 和 ViewTransfer。

验收使用本机 Chrome for Testing 156，分别检查开发页面与实际生产构建页面；出生测试为合成数据 `2000-01-01 20:00 / 上海 / UTC+08:00`，历史样本使用项目现有「承天寺夜游」记录。没有上传测试输入。

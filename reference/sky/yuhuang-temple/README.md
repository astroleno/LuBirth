## 二十八宿双版本

已完成 **28 幅原型 + 28 幅细线稿**，制作顺序为先完成全部原型，再依据各自原型生成线稿。资产文件、逐幅观察、绘画解释及生成记录见 [完整制作记录](full-set-generation.json)；[运行清单](../../../src/spikes/sky/data/chinese-art/manifest.json) 已注册全部 28 对。

[28 × 2 图绘总览](artwork-gallery.html) 可切换原型、线稿与实物照片；[完整交付与验证记录](../../../docs/handoff/2026-10-22-yuhuang-28-pairs.md) 标明通过项、偶发帧时波动、宽屏截图限制与真机待测项。

- 四象各七宿按传统次序排列；原型面板支持上一宿、下一宿、全部二十八宿、实物对照与返回线稿。
- 牛金牛、室火猪、参水猿、轸水蚓的动物在采用照片中不可辨认，未按名字擅自添加大型伴生动物。
- 鬼金羊掌中小像增加完整衣袍，属于当代绘画处理，页面和制作记录均明确标注。
- 图绘被裁切或遮挡的衣摆、动物身体、纹样由绘画补全；完整原型并非照片像素级修复。

## 使用与后续核实

2026-10-23 已补上 **28 幅逐幅配准第一轮**：每幅选取两个本宿恒星与原图部位对应，分别确定朝向、大小和落点，保留原图左右关系与比例。可打开[编排对照](placement-review.html)看调整前后、原图对应点及相邻两宿；[参数](placements.json)和[验证记录](../../../docs/handoff/2026-10-23-yuhuang-placement.md)明确区分投影检验与尚未成立的历史身体部位对应。

1. 图绘总览由实际注册资产生成；照片总览与图绘总览分开，避免把照片数误当成作品数。
2. 后续修订仍须逐尊对照近照与制作记录，被遮挡部分应另找照片，或明确列为绘画解释。
3. 官方晋城博物馆数字展页面本次遇到证书有效期错误，未绕过警告，未据此声称完成馆方造型核验。后续可用馆方图录、展览说明或授权高清图再校核摄影者题名。
4. 民间介绍对若干人物性别、手势、星宿用字的描述与照片题名存在需核对之处，本次不把未逐项核实的介绍直接变成生成要求。
5. 星空连线继续采用 Stellarium 宋代星官数据。玉皇庙造型属于另一视觉材料层；不能把两者组合说成同一时期的原始星图。
6. 辅助 HIP 星只控制图绘投影，图绘大小和摆位是当代构图。它们不改变恒星坐标、星等、色指数、星官成员或宿界，也不提供古代历史日期的新增真实性保证。

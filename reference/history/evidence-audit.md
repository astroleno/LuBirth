# 历史档案复核

应用以 `src/history/data/records.json` 的 150 条和 `supplemental-events.json` 的 3 条为底表。`evidence.json` 以稳定 ID 增补原历、钟点和场址依据。原档引文、来源列表、日序和哈希随原文件保留。补充证据的记录哈希同时涵盖底表记录哈希、本条证据及关联出处。旧观测保留原来的地点、钟点、换算方式和 UTC。

79 条仍保留条件性解释。引文多只给西历数字，未声明所用历法。B04-07 和 S15-09 的年号或干支只涉及年份，无法据此核对具体日序。N50-033、N50-034、N50-048 增补的机构资料支持事件本身，原档西历解释仍保留原等级。另复算 H006、H017、H023、H024 和 N50-026 的清历日序。H043 明确区分癸卯夜宿、翌日甲辰受立两条日序。

清历月首的样本取自 Y. T. Liu 的对照表，按年内公历日序保存于 `qing-calendar-sample.json`。日期计算采用普通月月首加上日数减一，闰月已反映在后续普通月的月首日序中。两历并载的引文可用历表核对数值对应，作者对历法的用意仍以原文为准。 [Y. T. Liu 历表](https://ytliu0.github.io/ChineseCalendar/table_period_chinese.html) · [资料来源与计算说明](https://ytliu0.github.io/ChineseCalendar/faq.html)

## 地点

34 条原先缺少观测点的资料中，H006 景仁宫、H017 储秀宫、H040 赫歇尔故居、H054 巴勒莫天文台、N50-033 杰斐逊大楼、N50-034 卢浮宫大画廊和 N50-048 白城体育场旧址新增场址。每条记录列出历史关联、地图出处、WGS84 和可理解的场址覆盖范围。房屋和宫院的点位代表建筑及附近范围，体育场点位代表拆除前的场址。OSM 建筑轮廓点取去掉闭合重复点后的顶点均值，具名标记直接采用站点经纬度。

| 仍须选地点的归档记录 | 复核时保留的定位限制 |

## 复验

`node scripts/prepare-history-evidence.mjs` 核对补充材料的哈希。编辑证据后，可用同一命令加 `--write` 更新哈希。`node scripts/test-history-evidence.mjs` 检查两个冻结档案、153 个 ID、清历月首复算、现场坐标、两种干支、表单与旧观测回读。旧 `scripts/test-history-data.mjs` 的 150 条上游重建输入 `output/history-dsh-fresh50-20261023-r2/catalog-150/records.json` 当前缺失，冻结档案校验使用 Git 内已有资料。
